# Spider-Man Modding Tool Context

## Glossary

**Modding Tool**: A software application that enables users to modify game assets for personal use.

**Texture Mod**: A modification that replaces or alters texture images in a game to change visual appearance.

**Extraction**: The process of retrieving game assets (like textures) from their storage format within game files.

**Rebuilding/Bundling**: The process of taking modified assets and packing them back into a format the game can read.

**Spider-Man Remastered**: The PC release of Marvel's Spider-Man with enhanced graphics, based on the 2018 PS4 game.

**Asset Types**: Different categories of game data including textures, 3D models, audio files, animations, etc.
